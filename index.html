RRematch турниры

Удобный список турниров в Rematch: добавляйте события с разных площадок, храните ссылки и даты. Добавление и удаление доступно только владельцу сайта через защищённый вход.

Форма добавления скрыта для гостей. Владелец может открыть её через «Вход владельца», чтобы добавлять и удалять турниры. Код доступа хранится только в браузере владельца.
